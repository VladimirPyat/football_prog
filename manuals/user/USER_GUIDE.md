# Инструкция для участника

Пошаговое руководство для роли **User** (участник конкурса): просмотр таблиц, вход, прогнозы, приватность до дедлайна.

> **Статус:** черновик. Скриншоты — плейсхолдеры (жёлтые блоки `📷 СКРИН`). После съёмки замените блок на `![описание](assets/имя-файла.png)`. Чеклист файлов: [assets/SCREENSHOTS.md](assets/SCREENSHOTS.md).

**Связанные документы:** продуктовая спека [`docs/03_user_scenarios.md`](../../docs/03_user_scenarios.md) · техсправочник [FRONTEND_REFERENCE.md](../dev/FRONTEND_REFERENCE.md)

## 1. Главная страница конкурса

**Кто:** посетитель (без входа) или участник.  
**URL:** `/contest/{contest_id}` (например `/contest/1`).

### 1.1. Лидерборд

На вкладке **«Лидерборд»** отображается сводная таблица участников:

- место, фамилия и имя;
- количество сданных прогнозов;
- статистика по типам попаданий (точный крупный счёт, точный счёт, разница, исход);
- бонусы 1 / 2 / 3;
- итог без бонусов, итог с бонусами, **общее число очков**.

### 1.2. Вкладка «Прогнозы»

1. Переключитесь на **«Прогнозы»**.
2. Выберите тур в выпадающем списке (1…N).
3. **Текущий тур до дедлайна** — для гостя заглушка «Будет доступно после дедлайна»; участник видит свои счета, у остальных — «Прогноз сделан».
4. **Опубликованные туры** — полная матрица: шапка «Счёт» и пары команд, строки участников с прогнозами, внизу статистика П1 / Х / П2.

### 1.3. Вкладка «Результаты»

1. Переключитесь на **«Результаты»**.
2. Для **неподведённого** тура — «Результаты будут доступны после подведения итогов».
3. Для **опубликованного** тура — в первой строке фактические счета матчей; на пересечении участник × матч — начисленные очки (0, 4, 8, 12); справа бонусы и итоги тура.

## 2. Вход и личный кабинет

**Кто:** участник с логином `USER`.

### 2.1. Вход

1. На любой публичной странице нажмите **«Вход»**.
2. В модальном окне введите **логин** и **пароль**.
3. Нажмите **«Войти»**.
4. При успехе — переход в **личный кабинет** (`/profile`). В шапке вместо кнопки «Вход» отображается ваш логин.

<p><span style="display:inline-block;background:#fff3cd;color:#664d03;padding:6px 12px;border-radius:4px;border:1px solid #ffc107">
📷 <strong>СКРИН:</strong> <a href="assets/user-04-login-modal.png"><code>assets/user-04-login-modal.png</code></a> — модальное окно входа
</span></p>

> **Первый вход по приглашению:** если выдан временный пароль, система перенаправит на установку постоянного пароля (`/auth/setup?token=…`).

### 2.2. Меню личного кабинета

На странице `/profile` слева — меню:

| Пункт | Назначение |
|-------|------------|
| **Контакты** | Email, VK, проверочный код, согласие на уведомления |
| **Сделать прогноз** | Переход на форму активного тура |
| **Просмотр результатов** | Результаты текущего / выбранного тура |
| **Личная статистика** | Заглушка (в разработке) |
| **Выйти** | Выход → главная `/` |

По умолчанию в центре — форма прогноза (если тур активен и дедлайн не прошёл) или результаты тура.

## 3. Ввод и редактирование прогноза

**URL:** `/contest/{contest_id}/predict/{round_id}`

### 3.1. Форма прогноза

1. Откройте форму через **«Сделать прогноз»** в кабинете или прямую ссылку.
2. Вверху — выбор тура (от текущего до последнего).
3. Список матчей: место проведения, дата/время, команды.
4. Для каждого матча — два поля счёта: `[Команда A] _ : _ [Команда B]`.

<p><span style="display:inline-block;background:#fff3cd;color:#664d03;padding:6px 12px;border-radius:4px;border:1px solid #ffc107">
📷 <strong>СКРИН:</strong> <a href="assets/user-06-predict-empty.png"><code>assets/user-06-predict-empty.png</code></a> — пустая форма прогноза
</span></p>

### 3.2. Правила ввода

- Только **целые числа от 0 до 20**.
- **Частичное сохранение запрещено** — нужно заполнить все матчи тура (обычно 8).
- Кнопка **«Сохранить прогноз»** активна только при 100% заполнении.
- Нечисловые символы и значения вне диапазона блокируются на уровне UI.

### 3.3. Сохранение и редактирование

1. Заполните все матчи → **«Сохранить прогноз»**.
2. После сохранения появляется кнопка **«Редактировать»**.
3. До **дедлайна тура** можно менять прогноз: «Редактировать» → правки → снова «Сохранить прогноз».

### 3.4. После дедлайна

Когда дедлайн прошёл:

- поля становятся **только для чтения**;
- кнопки сохранения / редактирования **неактивны**;
- повторная отправка через API отклоняется (`403`).

## 4. Приватность прогнозов (кратко)

| Момент | Участник (USER) | Посетитель (без входа) |
|--------|-----------------|------------------------|
| **До дедлайна** | Свои счета видны; у других — «Прогноз сделан» | Заглушка на вкладке «Прогнозы» |
| **После дедлайна** | Полная таблица всех прогнозов | Полная таблица (публичные данные) |

Статус тура при закрытии: `ACTIVE` → `CLOSED`. UI блокирует правки прогнозов.

## 5. Частые вопросы

**Не вижу ссылку «Сделать прогноз»** — нет активного тура с открытым дедлайном. Дождитесь активации тура организатором.

**Кнопка «Сохранить» серая** — заполнены не все матчи или есть ошибка валидации (проверьте диапазон 0–20).

**Хочу играть и быть организатором** — нужны **два разных логина**: `SUPERVISOR` для `/admin/*` и отдельный `USER`, приглашённый в конкурс. См. [API_GUIDE — организатор и участник](../dev/API_GUIDE.md#organizer-vs-participant-same-person).
